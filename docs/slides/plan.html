§1 Verdict first

What the factory is — and what it isn't

1

The method, mechanized — not a new trading idea

The stages are the manual gauntlet. What it buys is cost-per-hypothesis: the manual loop took ~a day; the harness runs in ~15 minutes. The bottleneck it does not remove is idea quality.

2

A factory is a multiple-comparisons machine

Automating search multiplies trials — exactly what inflates Sharpe. The answer is structural: trial ledger, holdout lockout, pre-registration as a blocking gate. Three outside "strategy pipelines" on the shelf demonstrate the failure mode; the pipeline shape is not the protection, the ledger is.

3

The named risk: the fifth plumbing project

Four predecessors died where plumbing met strategy. Countermeasures: freqtrade stays the engine, a golden test from week one, and the regression fixtures are the dead strategies themselves.

4

One deliberate refusal

No LLM meta-agent orchestrator. Authority enforced by prompt is negotiable by definition — here it is hash-checked signatures and plain code. LLM judgment lives inside stages, never between them.

§3 · §4 The pipeline's standing rules

Rules that wait for the day of temptation

Signatures, not vibes

factory approve records who/when/artifact-hash; tampering voids the signature and the orchestrator refuses to advance. factory reject records human kills with reasons — approve and reject pair on the record.

Automated sources are trial families

Any mechanism producing hypothesis cards without a human — a scanner, a scheduled survey, an LLM on cron — is a trial family with a pre-registered, signed budget; a spent budget halts the source. None exists today; the rule exists for the day the temptation comes.

The graveyard is ground truth

Every gate exists because something was measured in September 2026. Six corpses, each re-killed by the right gate in the test suite — the one asset a from-scratch factory would not have.

The ledger is deliberately humiliating

Every backtest, hyperopt, screen and re-run appends — the count only goes up, which makes the deflated Sharpe honest and doubles as the cost odometer against the US$100/month budget.

§14 M6 executed — the rehearsal

Gates passed. The human killed it anyway.

The signed toy looked genuinely tempting — zero-fee +99.8 %, cost coverage 24×, OOS mean +5.18 %, SR 1.02 — which is the design, not a contradiction: the dossier handed HG2 three clean counts.

Count 1 · protocol
107 d
max realized hold vs 30-day tripwire

Its own signed prereg: any hold > 30 days fails the run. The agent-drafted tripwire was the sharpest criterion in the document — and it means the 30-day purge was undersized, tainting even the OOS table.

Count 2 · concentration
48 %
of profit in one month · ceiling 40 %

The failure mode the deterministic gates provably cannot see in-sample; skew +3.7 and kurtosis 72 say the same thing.

Count 3 · deflated Sharpe
0.091
DSR vs pre-registered 0.5 floor

Within the 24-trial comparable family. Recorded via the new factory reject verb — the missing half of the human gate.

lesson

Purge sizing from typical hold is dangerous — condition-based exits have unbounded tails. Size purges from the realized maximum, which the dossier now always reports.

§15 M7 executed — deploy & observe

Rehearsed locally, then live on GCP

factory-dryrun · e2-small · europe-west1-b

Bot running dry-run on 17 pairs with a US$2,000 paper wallet; observer snapshotting every 5 min; parity writing daily. ≈ US$13/month against the budget. No public ports, no exchange keys on the box.

Silence never looks like success

The observer's alert path fired for real during rehearsal — first poll landed while freqtrade was still booting. Failures are written as snapshots too.

Three ops lessons, baked into provision.sh

1 · Binance geo-blocks US IPs — the first VM, in us-central1, died with HTTP 451; recreated in Belgium, and the script's default zone now says why.

2 · docker-compose-v2 is not a Debian 12 package — the startup script silently lost docker; now installs docker.io + the compose v2 plugin and waits for docker before proceeding.

3 · A root-created data dir is unwritable for uid 1000 — the local rehearsal masked it because the host uid happened to match; provision now pre-creates it chowned.

§10 Honest caveats

What the factory does not fix

1

It does not refill the idea well

Phase 2 paused because ideas ran out, not because testing was slow. A faster gauntlet with weak inputs just fills a graveyard faster — cheap, but not progress by itself.

2

Concentration is not screenable

Proven, not assumed: G5-style failures surface only at the tear sheet. S2 cannot promise that S5 won't kill.

3

LLM-written strategies are a lookahead risk

lookahead-analysis is blind to cross-sectional designs. Mitigations: per-strategy runs, a generated causal test per implementation, and the human actually reading the code at HG1/HG2.

4 · 5

Costs, and the dual-sync tax

API tokens, the VM invoice, the temptation to run S2 in bulk — the trial ledger doubles as the odometer. And Dropbox syncs what git ignores: run artifacts must stay lean.

§17 Next steps — research topics

The reading queue

1 · Factory-as-skills

Package the discipline as Claude Code skills so a plain session behaves like the factory. Acceptance: the skills alone must re-kill the graveyard, for the same reasons.

2 · Jev typed decisions

Typed values with confidence scores for non-generative decision points (card extraction, screen routing, graveyard kinship). Validate the vendor claims against the model each stage actually uses — never a frontier default.

3 · Caches (Headroom)

LLM-context compression + engine-result caching on exact content hashes. The odometer judges it: compression that breaks provider cache reuse can raise the bill.

4–6 · Feature families for S1

Causal EMD, MASS similarity search, cross-asset regime features — all under the causal-fit rule: anything fitted must use data ≤ t, frozen, rolled forward; every clustering choice is a ledger trial.

9 · ML diagnostics

For self-labelled candidates: report agreement with the naive rule that generated the labels — the model must beat the rule, not the coin (86 % OOS accuracy was 85 % rule-agreement).

The through-line

Every topic ends at the same place: a measured comparison on the graveyard fixtures, counted on the ledger. Validate, don't repeat.
