§1 Principles

Four commitments everything else follows from

01

Deterministic core, LLM edges

The orchestrator is a plain state machine over manifests. Claude Agent SDK sessions run inside Intake / Research / Pre-register / Implement with scoped prompts and tool allowlists. LLM output never self-certifies — deterministic gates decide every transition.

02

A factory is a multiple-comparisons machine

By default, automation just multiplies trials. The structural answers: an append-only trial ledger (makes deflated Sharpe computable), a holdout lockout (unmountable without a signed approval), and pre-registration as a blocking human gate before any fold runs.

03

The graveyard is the test suite

Six hypotheses were manually tested and killed in Sep 2026, each for a measured, diagnosed reason. Their recorded numbers are fixtures: the factory must re-kill each at the right stage for the right reason.

04

The engine is freqtrade, across a process boundary

The factory shells out to the in-repo lab's docker images — freqtrade-lab:2026.8 for backtests, :2026.8-research for screens/tear sheets, never mixed (the research image downgrades pandas). Strategies run via --strategy-path; the lab's tree is never written to.

§3 Gates · the cheap kills (S2)

Screen gates — each calibrated on a corpse

GateTestKills fixture
Noise floor Per-trade sd at intended holding period vs the edge gate; trades needed ≈ (sd/edge)²·k vs trades the history supplies. Gate inside error bars ⇒ untestable ⇒ kill. H4 Kalman hedge-ratio spread — sd ≈ 15 pp vs 0.6 % gate
Cost rule Gross edge per trade must be ≥ 3× round-trip cost at the intended timeframe. H2 trend-following — −0.04× coverage
Zero-fee sanity Negative at zero cost ⇒ no signal at all. Strategy005 — −49.55 % at zero fees
Factor screen IC per horizon with t-stats, quintile forward returns, turnover — always beside an ORACLE (look-ahead) arm and a NOISE arm for scale. H1/H3 factor — IC negative at 9/9 horizons

§3 Gates · the deep kills (S5)

Validation gates — what screens can't see

GateTestKills fixture
Control arm Candidate must beat its own untuned defaults out-of-sample. H1 tuned — lost 6 of 7 folds
G-passive Equal-weight buy-and-hold of the same universe, scaled to realized exposure, compared on Sharpe, split by rising/falling windows. H3 five-year — Sharpe 0.81 vs 1.64
Concentration Tear-sheet level only — provably not screenable in-sample: share of profit in best month / trade cluster. H3 holdout — one month = 78 % of profit
Deflated Sharpe Bailey / López de Prado DSR using the trial count from the ledger, never a guess. calibrated at M4
Data integrity Gaps, duplicate/missing candles, zero-volume stretches, cross-provider deviation bands (bands, not equality — venues differ). synthetic corruption fixtures

§5 Data

Two providers, two partitions

Primary — Binance

OHLCV via freqtrade download-data. Bulk data lives outside the repo and outside file sync (~/freqtrade-data/ convention) — regenerable, never committed.

Secondary — ccxt, second exchange

Integrity cross-check only, never backtested. Catches gaps, duplicates and bad files via deviation bands — venues legitimately differ, so bands, not equality.

research/ vs holdout/

The store is partitioned by date range. Research runs mount research/ only; mounting holdout/ takes a signed HG2b token, and the spend is permanent.

The holdout ledger's opening balance

Seeded from the predecessor project: 2021–2025 folds spent, 2026 spent, 2019–2020 the last clean window — and the calendar accrues new windows from here.
